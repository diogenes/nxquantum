# H1.5 TTFR rehearsal (2026-10-30)

**This is a rehearsal, not the gate evidence.** It runs the consumer flow
against `mix hex.build --unpack` of main (branch rebased onto origin/main bb17b47; built with
`NXQ_ENABLE_EXLA=0 NXQ_ENABLE_TORCHX=0`) as a path dependency, with the
canonical getting-started snippet
`test/fixtures/docs/getting_started_first_result.elixir` (RY(1.2) on one qubit,
`Estimator.run/2` on Z wire 0, returns `Nx.to_flat_list(result.values)`). The
harness evaluates the snippet with `mix run -e` and inspects its return value.
The snippet is the in-tree default (`--snippet` not passed); it is on main
since H1.5 PR-2. Gate 2 closes only on a published 0.12.0.

Human reading time is not measured. Toolchain installation is not measured.
The numbers are an internal, environment-specific reference, not a general
performance claim.

Harness: `bench/ttfr/run.sh` at commit fbe7665 (`script_ref` in
`environment.txt` is generated by the script via `git rev-parse` on a clean
tree). Environment: `environment.txt`. Each run used fresh empty `MIX_HOME`,
`HEX_HOME`, `HEX_CACHE_DIR` and XDG dirs; `mix local.hex` and `mix local.rebar`
ran inside the timed flow. Resolved Nx: 1.0.0.
